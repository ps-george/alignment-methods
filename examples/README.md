# Examples

Real-world cases of methods in this library working — or visibly failing to work — in practice. Anonymised.

The point of these examples is to give a reader who has read the methodology a concrete sense of what it looks like when applied. Methods read as plausible on the page; what makes them durable is recognising them in practice.

## Files

- [`causal-arc-in-action.md`](causal-arc-in-action.md) — examples of causal-arc execution in practice, with brief commentary.

## Contributing examples

If you have an anonymised before/after where a method clearly changed agent behaviour, add it here. Keep entries short — one paragraph of setup, one of behaviour observed, one of takeaway is plenty. The examples are illustrative, not evidentiary; the benchmark is where evidence lives.
